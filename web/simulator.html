Giả lập app

Đây là bản mô phỏng chạy trên trình duyệt để bấm thử app thay vì gõ curl hay mở Unity. Nó gọi thẳng vào server đang chạy bằng cargo run trên máy bạn.

Chưa kiểm tra kết nối

Nếu chấm đỏ: mở terminal, cd server, chạy cargo run, để cửa sổ đó chạy nền rồi quay lại đây bấm lại.

Vì đây là file HTML mở trực tiếp (không phải app thật), mọi dữ liệu vẫn nằm ở server RAM của bạn — tắt server là mất, đúng như thiết kế "chưa cần DB".
